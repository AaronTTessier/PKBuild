# PKBuild
## A Teambuilding and Pokedex organizing tool

---

### (NOTE: Project is still a work-in-progress, not all features are currently implemented)

PKBuild is a tool for organizing, creating, and analyzing teams and team composition, both in casual and competitive standards.  This tool works even in the story mode of the games, past and present, along with the official online competitive scene, from the mainline games all the way to Pokemon Champions.

### PKBuild is available on Windows, macOS, and Linux

# Features

---
PKBuild supports these features:

- Create and edit teams.
- Save teams in a local database, with optional password protection.
- Analyze teams for various effects (type coverage, base stats, etc.).
- Save boxes of Pokemon for easier team creation and editing.
- Organize Pokemon based on current game.
- Track Ribbons for Ribbon Masters.
